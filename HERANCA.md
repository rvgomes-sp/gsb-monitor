# Nota de consolidação

Este repositório consolida o projeto GSB Monitor numa base única e limpa.

## Origem dos arquivos

**Código Python (coletor, motor, ferramentas):** desenvolvido e validado em
produção — a coleta de 12/08/2026 gerou 27 oportunidades reais (R$ 403,7 MM).
Esta é a base ATUAL e oficial do sistema.

**Documentação de governança (matriz 14 eventos, regras, manual PNCP v2.5):**
herdada do repositório anterior `compras_gov`. Continua válida e é referência.

## Legado

O repositório `compras_gov` continha uma implementação anterior em PowerShell
(`.ps1`). Essa versão foi descontinuada em favor da implementação Python, mais
adequada à evolução do projeto (Supabase, APIs, automação). O repositório
antigo permanece como arquivo histórico.
